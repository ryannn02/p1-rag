## 二、关键发现：I-13（HTML 解析把正文里的数字当页码删掉）

**现象**：语料里出现「具有高级职称的教师每年内完成**　**分科研分值」这样的残缺条款，句子读得通，
**不逐字核对根本看不出来**。对应 `#207` 那道题的答案就是照抄了这条残缺条款。

**根因链**（逐环节验证过，两处叠加才出事）：

1. `parse_html` 用 `node.get_text("\n", strip=True)` → 每两个文本节点之间插一个换行；
2. Word 导出的 HTML 习惯把数字单独包一个 `<span>`：`…完成</span><span>10</span><span>分…`；
3. 于是 `10` 独占一行；
4. `clean_text` 的页码规则 `^\s*[-—\s]*\d{1,3}\s*[-—\s]*$` 把任何独占一行的 1–3 位数字当页码删掉。

```
原始 HTML : 具有高级职称的教师每年内完成10分科研分值
parse_html: 具有高级职称的教师每年内完成\n10\n分科研分值   ← 数字已独占一行
最终 chunk: 具有高级职称的教师每年内完成分科研分值        ← 数字没了
```

**实测规模**（对 `data/raw` 里 227 份原始 HTML 逐份做 A/B，只换解析方式与页码规则，其余不动）：

- **80 份丢过正文数字，合共 1418 处**
- 小数字最多：「10」40 处、「5」86 处
- 关键数字也中招：体育部考核条例的 `10分/5分` 科研分值、助学金档位 `3300/3800`、
  学业奖学金 `8000`、违纪处分办法文号 `119/2021/41`

**修法**（`scripts/build_corpus.py`，改了两处）：

1. 新增 `html_text()`：先给块级标签后面插换行，再 `get_text("", strip=False)` —— **只在块级标签处断行**
   （不能用 `strip=True`：它会把刚插进去的换行当空白剥掉，整篇粘成一行，这个坑踩过）；
2. 页码规则收紧成只认带破折号的页码，没装饰的页码宁可留作噪声，也不吃正文。
   代码里留了 `# ponytail:` 注释写明这个取舍。

**回归**：解析 `261/263` 不变、`pytest` 29 项通过、`Recall@5` 仍 `19/20`、端到端 `6/6`。
