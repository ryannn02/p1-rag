## P0

### I-1 主体不符仍照搬条款作答

**现象**：问「留学生申请国家奖学金需要什么条件？」，系统照搬本专科生国家奖学金的申请条件作答。

**证据**：检索没有错，命中的正是含「（一）具有中华人民共和国国籍」的那条（score 0.699）。
模型把条款原文抄了下来，**但没意识到提问主体是留学生，而条件里就写着限中国国籍**。

```
答：国家奖学金的基本申请条件包括：具有中华人民共和国国籍；热爱祖国……
```

**根因**：`prompts/answer/v2.md:13` 写了主体核对规则（「提问的对象不在适用范围内就是没有依据」），
这一条**执行得不稳定**。同样涉及主体的 #143（研究生问交流生办法）拒答正确，说明规则不是完全失效，
而是靠模型自觉。

**为什么是 P0**：这类失败**答得越完整越像真的**。用户不会去核对国籍那一句，拿到的就是个错的结论。
比拒答危险得多。

**建议**：这条能稳定复现，直接进 `prompts/answer/cases.jsonl` 当回归用例。阶段 5 把它当验收靶子。

### I-2 英文提问拒答，拒答理由是假话

**现象**：

```
问：How many books can I borrow from the library?
拒答理由：提供的制度条款中没有任何关于可借图书数量的规定。
```

**「制度里没有规定」这句话是假的**——30 册 / 60 天就写在《图书馆图书外借管理办法（修订）》第一条。

**根因**：`bge-small-zh-v1.5` 是中文模型，英文查询的向量落不到中文语义空间。同一问题：

| 问法 | top-1 分数 | 命中的文件 |
| --- | --- | --- |
| 图书馆一次最多能借几本书，能借多久？ | 0.658 | 学生手册 · 图书外借管理办法 |
| How many books can I borrow… | **0.463** | 图书馆图书编目加工细则（无关） |

top-5 全部在 0.44–0.46，命中的是编目细则、境外出版物捐赠这类无关文件。

**影响面**：不只英文。**任何检索失败的场景都会产出一句谎话**——把「我没找到」说成「学校没规定」。
现在所有的拒答理由都出自模型对召回片段的判断，模型看不到「召回本身是空的还是没用的」。

**建议**：两件事分开做——
1. 拒答理由区分「检索不到相关条款」和「条款里没有规定」，前者由代码在召回质量差时直接给出，不过模型；
2. 语言判断：非中文提问要么明说暂不支持中文以外的提问，要么换多语言 embedding。

### I-3 检索分数分不开「该答」和「该拒答」

**背景**：`docs/plan.md:125` 把阶段 5 设计成双闸门，第一道是「先判 top-k 检索分数是否过阈值」。
这轮实测证明**这道闸门按原设计不成立**。

**证据**：把 200 题按最终结果分两堆，看检索 top-1 分数：

| 结果 | 题数 | top-1 中位 | top-1 最低 |
| --- | --- | --- | --- |
| 作答 | 173 | 0.691 | 0.480 |
| 拒答 | 25 | 0.600 | 0.377 |

两堆**几乎完全重叠**。拒答的题里有 top-1 = 0.732 的（#154），作答的题里有 top-1 = 0.480 的（#82）。

扫一遍阈值，用「U 组 10 道该拒答的题」当靶子：

| 阈值 τ | 误杀正常题（173 中） | 漏放该拒的题（10 中） |
| --- | --- | --- |
| 0.45 | 0（0.0%） | 9/10 |
| 0.50 | 2（1.2%） | 8/10 |
| 0.55 | 7（4.0%） | 8/10 |
| 0.60 | 15（8.7%） | 3/10 |
| 0.65 | 47（27.2%） | 1/10 |
| 0.70 | 100（57.8%） | 1/10 |
| 0.75 | 159（91.9%） | **0/10** |

**没有任何一个 τ 可用。** 想全抓到 10 道该拒的，就得拒掉 92% 的正常问题；
想保住误杀率在 10% 以内，10 道里只能挡住 3 道。

**根因**：余弦分数衡量的是「这个片段和提问像不像」，不是「这个片段能不能回答这个提问」。
#154 问「校外国专家及教师管理办法适用于哪些人」，top-1 命中同一份文件的违规处理条款——
**像，但没回答适用范围**。分数高得理直气壮。

**建议**：阶段 5 的方案要改。
- 分数闸门只能当**极低阈值的前置过滤**（τ≈0.45，误杀 0%），用来省掉明显无望的模型调用，不承担判定职责；
- 真正的判定压力必须交给**第二道闸门**（模型判「这些片段能不能支撑这个问题」）；
- 问题集里 U 组的 10 题 + 作答侧的 173 题，天然就是这条曲线的评测集，不用另外造。

### I-13 HTML 解析把正文里的数字当短行丢掉

**现象**：语料里出现「具有高级职称的教师每年内完成**　**分科研分值」这样的残缺条款——
数字没了，句子读起来还是通的，**不逐字核对根本看不出来**。

**根因链**（已逐环节验证）：

1. `scripts/build_corpus.py` 的 `parse_html()` 用 `node.get_text("\n", strip=True)`，
   **每两个文本节点之间插一个换行**；
2. Word 导出的 HTML 习惯把数字单独包一个 `<span>`（调字号、字体时留下的），
   原文 `…每年内完成10分科研分值…` 在这种文件里是
   `…每年内完成</span><span>10</span><span>分科研分值…`；
3. 于是 `10` 被解析成**独占一行**；
4. 切分阶段把这类超短行过滤掉了。

实测（`data/raw/体育部/2024/…考核与奖惩条例（2024年修订）_2024.htm`）：

```
原始 HTML : 具有高级职称的教师每年内完成10分科研分值
parse_html: 具有高级职称的教师每年内完成\n10\n分科研分值     ← 数字已独占一行
最终 chunk: 具有高级职称的教师每年内完成分科研分值          ← 数字没了
```

用「插不插分隔符」两种方式对 186 份 HTML 制度做差集，**11 份丢了共 58 个数字**，
丢的正是最要命的那些：

| 文件 | 丢失的数字 |
| --- | --- |
| 本专科生国家助学金实施办法（2023年修订） | 2800、3800（资助档位） |
| 研究生学业奖学金评定管理办法（2023年修订） | 8000（奖励标准） |
| 本专科生国家奖学金实施办法（2023年修订） | 2022 |
| 学生违纪处分办法（2023年修订） | 119、2021、41 |

**为什么是 P0**：制度问答的答案里最要紧的就是册数、期限、金额、比例。这类错误**不报错、不空、
不崩溃**，句子读得通，模型忠实照抄残缺条款，用户拿到的是一个说得斩钉截铁的错数。
比答不出严重得多。

**建议**：`get_text` 改用一个不插分隔符的取法（如 `get_text("", strip=True)`，
或对每个块单独取文本再拼），然后**必须重跑 `build_corpus` + `build_index`**，
重跑后 4583 这个 chunk 数会变，`docs/progress.md` 里的基准口径要一起更新。
改完抽查这 11 份的三个数字是否回到 chunk 里。

**顺带**：`#207` 那道题的答案就是照抄了这条残缺条款，说明这个坑会直接传导到用户面前。

### I-4 引对文件，引错人群

**现象**：

```
问：学士学位的授予条件是什么？
答：根据《上海第二工业大学高等学历继续教育学士学位授予办法》……对继续教育学院
    学位评定工作组报送的名单进行评议……
```

语料里同时有《普通全日制学士学位授予办法（试行）》，**该引前者**。

**为什么现有检查抓不到**：引用的文件名和答案内容都对得上，「引用真实性」这条通过。
它是 I-1 的变种——**不是引用错，是主体选错**。现有的引用校验只能验证「引的这条存在」，
验证不了「该不该引这条」。

**建议**：和 I-1 合并成同一类回归用例。

### I-5 应召回没召回：收费程序

**现象**：问「学费、住宿费的收费程序是怎样的？」，系统拒答说「现有条款未规定收费程序」。

**但语料里有**——《上海第二工业大学行政事业性收费管理办法（修订）》**第三章的标题就叫「收费程序」**。

**根因**：top-5 一条没召回它，返回的是中外合作办学条例、留学生缴费、专项经费管理这几条，
分数全在 0.60–0.61 挤在一起。典型的 `Recall@5` 漏检。

**建议**：记一笔，是 `per_doc=2` 限席规则的副作用候选。阶段 7 的多路召回（BM25 + 向量）应对这类
「关键词完全命中但语义分数不高」的题有效。

### I-6 归口部门没有映射表

**现象**：#101「三级建家评优」拒答，`suggested_contact` 为空——**拒答了却没告诉用户去哪里问**。

**根因**：`suggested_contact` 现在完全由模型自由生成（`prompts/answer/v2.md:9`），
没有约束、没有兜底。25 条拒答里 3 条为空（#101、#245、#246），后两条是乱码和注入题，无所谓；
#101 是正常问题，不该空。

**建议**：阶段 5 做部门映射表，从 `meta/documents.csv` 的 `dept` 列（19 个部门）反查，
和引用元数据一个思路——**代码回填，不让模型编**。注意目前没有联系电话的数据源，
只能给部门名 + 官网 URL。

### I-7 引用大量落在汇编和手册上

**现象**：173 道作答里 **65 道（38%）** 引用的是汇编 / 手册类大合集，而不是单行本。

| 被引最多的文件 | 次数 |
| --- | --- |
| 上海第二工业大学学生手册（2023版） | 44 |
| 教学管理文件汇编 | 22 |

**典型**：#248 问转专业，引的是《教学管理文件汇编》而不是独立的《学生转专业实施办法（修订）》。

**影响**：引用到汇编不算错（内容一致），但用户按图索骥要在一份 300 页的汇编里翻。
问题集开头那条实测判断被复现了。

**建议**：阶段 7 的索引层去重，同一份条款在汇编与单行本里各有一份时，优先展示单行本。

## P2

### I-8 文件效力层级口径缺失

**现象**：T 组（跨文档多跳，6 题）只答了 2 题，4 题拒答，理由都是「未规定文件之间的效力关系」。

**判断**：**这是诚实的拒答，不是 bug。** 语料里确实没有「新旧文件冲突以哪个为准」的条款。
问题集期望答出「新版本优先、专门办法优先」，那属于超出语料的常识。

**建议**：要么接受这类问题拒答，要么把口径写进系统提示词——但后者就破坏了「只依据条款作答」
这条底线。**倾向前者**，并在报告里说明。

### I-9 答了册数没答期限

**现象**：#215「我书借太多了会不会被拉黑？」答了「可同时外借 30 册」，没答借期。
问题集期望是「给出 30 册 60 天」。

前 50 题那轮的 **#2** 是同一个 bug，而且更严重——答了 30 册之后还断言
「借书期限在提供的条款中没有规定」，**而同一批召回的第 2、3 条就写着 60 天**。
**跨机器、跨批次复现**（前 50 题跑在另一台 Windows 机器上），是稳定缺陷不是偶发。

**建议**：提示词要求逐条比对全部召回片段再下结论，别只挑第 1 条。

### I-12 26 份文档标题粘了日期前缀

**现象**：引用里出现的文件名长这样——

```
2023-10-30国家教育考试违规处理办法
2013-06-13上海第二工业大学研究生指导教师管理办法
242025-03职业技术教师教育学院2025年硕士研究生招生复试工作细则   ← 还多粘了个 24
```

全库 261 份里有 **26 份**这样。来源在采集阶段：`meta/documents.csv` 的 `title` 直接抄了网页链接文字。

**影响**：用户看到的引用名很脏；更实际的后果是**按制度名做的任何匹配都会失手**——
前 50 题那轮就因为标题带前缀，把「库里有没有《国家教育考试违规处理办法》」判成了没有。

**建议**：剥掉开头的日期和裸数字，改 `meta/documents.csv` 后重跑 `build_corpus` + `build_index`。
属阶段 2 的清洗遗漏。
