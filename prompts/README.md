# 提示词约定

## 目录结构

一个提示词一个目录，目录名即提示词名：

```
prompts/<名称>/v1.md          提示词主体
prompts/<名称>/cases.jsonl    回归用例（必须与提示词同目录）
```

## 版本规则

- 文件名带版本号，格式 `v<整数>`：`v1.md`、`v2.md`。
- `v1.md` 必须一直保留，它是历史链的起点，删了就回滚不了。
- 改提示词 = 新建 `vN+1.md`，**不要原地修改旧版本**。
- 切换默认版本要在 PR 里附新旧版本的对比结果。

## cases.jsonl 字段

每行一个 JSON 对象：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `input` | 是 | 该提示词的输入样例 |
| `expected` | 是 | 期望输出（金标准），回归时与模型输出比对 |
| `note` | 否 | 这条用例为什么存在、属于哪类失败 |

## 校验现状

- 阶段 0–3：只做结构校验（`pytest -q`），不调用模型，不烧 token。
- 阶段 4 起：补 `pytest -m llm` 回归执行器，读 cases → 调模型 → 与 `expected` 比对 → 输出与基线的 diff。
- 没有 `expected` 的用例在回归里没有意义，加用例时一次写全。
